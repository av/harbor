### [lmdeploy](https://lmdeploy.readthedocs.io/en/latest/get_started.html)

> Handle: `lmdeploy`<br/>
> URL: [http://localhost:33833](http://localhost:33833)

A toolkit for compressing, deploying, and serving LLMs, from the MMRazor and MMDeploy teams. Serves an OpenAI-compatible API via `lmdeploy serve api_server`.

> **NVIDIA-only.** The upstream `openmmlab/lmdeploy` images are CUDA-only — this service requires an NVIDIA GPU with the NVIDIA Container Toolkit installed. It will not run on CPU-only or AMD/ROCm hosts.

#### Starting

```bash
# [Optional] pre-pull the image (multi-GB, CUDA-based)
harbor pull lmdeploy

# Start the service
harbor up lmdeploy
```

Models are downloaded from Hugging Face on first start and cached in Harbor's shared HF cache. For gated models, provision a token first with `harbor hf token <your-token>`.

#### Configuration

Following options can be set via [`harbor config`](./3.-Harbor-CLI-Reference.md#harbor-config):

```bash
# Host port for the OpenAI-compatible API
HARBOR_LMDEPLOY_HOST_PORT      33833

# Image tag for openmmlab/lmdeploy
HARBOR_LMDEPLOY_VERSION        latest

# Hugging Face model ID to serve
HARBOR_LMDEPLOY_MODEL          Qwen/Qwen3.5-4B

# Extra CLI args appended to `lmdeploy serve api_server`
HARBOR_LMDEPLOY_EXTRA_ARGS     ""
```

Example:

```bash
harbor config set lmdeploy.model Qwen/Qwen3.5-4B
harbor config set lmdeploy.extra_args "--session-len 8192"
harbor up lmdeploy
```
